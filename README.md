# Evervale — The Faceless Woman

Мистическая игра для практики английского. Дело №17: женщина, которой никогда не существовало.

## GitHub Pages

Это статический сайт без сборки и сервера. `index.html`, таблицы стилей, скрипты и папка `assets` должны лежать в корне репозитория.

В **Settings → Pages** выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и сохраните. Файл `.nojekyll` отключает ненужную обработку Jekyll.

Сайт использует относительные пути и работает по адресу проекта GitHub Pages. Вход в GitHub для игроков не нужен.

## Файлы

- `index.html` — игровые экраны.
- `game.js` — сюжет, задания, уровни и сохранения.
- `game.css` — оформление игровых сцен.
- `chronicle.css` и `interface.css` — главный экран, книжный разворот и адаптивная верстка.
- `interface.js` — меню, отображение прогресса, смена уровня и героя.
- `twilight.css` — яркая сумеречная тема: цветное небо, светлячки, стеклянные панели, свои цвета у каждого уровня и героя.
- `heroes3d.js` — «живые» портреты героев: WebGL-параллакс с глубиной, 3D-наклон карточки за курсором, дыхание, свет и частицы. Если WebGL недоступен (или игра открыта как файл без сервера), карточки всё равно наклоняются в 3D поверх обычных картинок.
- `assets/` — локальные изображения WebP и музыка MP3.

Прогресс сохраняется в браузере игрока. При переходе с другого домена прежнее локальное сохранение автоматически не переносится.

Игровые материалы принадлежат автору проекта. Публичная публикация кода не предоставляет отдельную лицензию на использование материалов.
